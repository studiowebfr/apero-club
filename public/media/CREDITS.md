# Crédits médias

Aucun média externe n'est utilisé dans cette version du site : tous les
visuels sont des placeholders générés en CSS/SVG (dégradé ambre + grain),
voir `src/components/ui/GradientScene.tsx`. Aucune photo de banque, aucune
image de marque tierce.

Si des vidéos libres de droits (Pexels, Coverr...) sont utilisées comme
placeholder temporaire en attendant le shooting du client, liste-les ici
avec leur source et leur licence, par exemple :

```
hero-placeholder.mp4 — Pexels, licence Pexels (pas d'attribution requise) — https://www.pexels.com/...
```
